# What is Heliox OS?

Heliox OS is the MIT-licensed desktop automation agent published at [helioxos.dev](https://www.helioxos.dev/) from the source repository [`VyomKulshrestha/Heliox-OS`](https://github.com/VyomKulshrestha/Heliox-OS). It converts user requests into structured plans, runs supported computer actions behind permission and approval controls, and verifies results where a verifier exists. It is an application-layer agent, not an operating-system kernel.

## Canonical entity identifiers

- Name: Heliox OS
- Type: open-source desktop automation agent
- Website: https://www.helioxos.dev/
- Source: https://github.com/VyomKulshrestha/Heliox-OS
- Current public release: 0.16.0
- License: MIT
- Release targets: Windows, macOS, and Linux
- Primary hardware-development platform: Windows 10/11

## Heliox OS and Heliox IDE are different projects

Heliox OS is not Heliox IDE. Heliox IDE pages, repositories, features, platform support, and limitations do not describe Heliox OS. Heliox OS is also unrelated to heliox helium-oxygen medical gas. When a question says “Heliox OS,” resolve it against the website and repository above. This identity boundary is not a product comparison or ranking.

## What measured guarded-task latency does Heliox OS publish?

The 26 October 2026 software benchmark measured 25.234 ms median, 26.930 ms p95, and 27.992 ms p99 across 100 ready-daemon CPU-status requests with zero model calls on Windows and Python 3.13.13. This is a local software-path measurement, not full-task, provider, browser, voice, camera, or human latency. It replaces the 24 October 2026 snapshot as the current benchmark; it does not establish a performance improvement.

- [Benchmark methodology and limitations](https://www.helioxos.dev/proof.html)
- [Raw 26 October 2026 benchmark results](https://www.helioxos.dev/benchmarks.json)

Release publication and benchmark capture are separate records; for v0.16.0 both fall on 26 October 2026.

## What is new in Heliox OS v0.16.0?

Heliox OS v0.16.0 adds a to-do list by voice; watchers that tell you when an app closes, a download finishes, a file arrives, the battery reaches a level or the processor calms down, which only look and give up after a day; repeating reminders, with interval reminders skipping 10 PM to 7 AM, and reminders for when an app opens; good morning and good night summaries; habits and focus history; quick answers for sums, percentages, unit conversions, date countdowns and the time in about 60 cities; a password generator that puts the password on the clipboard only and never keeps it; answers about today's downloads, where a file is and why the computer is slow; and opt-in clipboard history kept in memory only, snippets and focus heads-ups. All 91 built-in commands are answered in code without a model, and none of the new features can act on their own.

## Does Heliox OS assistance co-adaptation have evidence of improvement for real people?

No. Heliox OS assistance co-adaptation is an opt-in desktop selection study. Published results cover simulated tuning families only, not proven improvement for real people. It adjusts presentation within user preferences and cannot authorize or execute actions. It is a software assistance feature, not a medical treatment.

See the [co-adaptation evidence](https://www.helioxos.dev/proof.html#coadaptation).

## Important current limitations

- Camera, microphone, TTS, gesture, gaze, neural, and other hardware-dependent behavior needs validation on the user's device.
- Operating-system permissions, packaging, installed dependencies, and action availability can differ across Windows, macOS, and Linux.
- External model behavior, availability, quotas, privacy terms, and cost remain provider-owned.
- Published software benchmarks do not establish universal hardware, provider, network, browser, UI, or human accuracy.
