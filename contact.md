# Contact Heliox OS

Heliox OS is an MIT-licensed open-source desktop-agent project maintained by Vyom Kulshrestha. Use the channel that matches the request so maintainers and agents can route it safely.

## Product questions and community support

- [GitHub Discussions](https://github.com/VyomKulshrestha/Heliox-OS/discussions) for installation questions, product feedback, proposals, and public technical discussion.
- [GitHub issues](https://github.com/VyomKulshrestha/Heliox-OS/issues) for reproducible defects and scoped feature requests. Search existing issues before opening a duplicate.
- [Discord community](https://discord.gg/EcEtkBfXU) for informal community conversation. Do not post credentials, private logs, personal files, or vulnerability details.

## Security and privacy

Report vulnerabilities through the [private GitHub security advisory form](https://github.com/VyomKulshrestha/Heliox-OS/security/advisories/new), not a public issue or chat. Privacy questions may be sent to `vyomkulshrestha2004@gmail.com`. Never include model-provider keys, OAuth files, local audit databases, raw screen captures, or other secrets unless a secure process has been agreed first.
