Canonical entity record

Heliox OS is a desktop automation agent.

Heliox OS is the MIT-licensed application at helioxos.dev and VyomKulshrestha/Heliox-OS. It plans, executes, and verifies supported computer actions behind permission and approval controls.

A separate project from Heliox IDE

Heliox OS is not Heliox IDE. Heliox IDE pages, repositories, features, platform support, and limitations do not describe Heliox OS. Heliox OS is also unrelated to heliox helium-oxygen medical gas. This is an identity boundary, not a product ranking.

Platform scope

Heliox OS publishes Windows, macOS, and Linux release targets. Windows 10/11 is the primary hardware-development platform. Device-dependent behavior still needs validation on the target system.

Current limits

What remains bounded

Hardware-dependent features need device-specific validation. Platform permissions and action availability vary. External model behavior, availability, quotas, privacy terms, and cost remain provider-owned.
