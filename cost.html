Heliox OS / Cost
Transparent cost

Free core. Your choice of compute.

Heliox OS is MIT-licensed open-source software with no purchase price. Your real cost depends on whether you use existing hardware and local models or connect paid external services.

Core: $0No required subscriptionNo hosted plan announced
Free

Heliox core

The desktop application, Python daemon, declared action system, local records, plugin framework, and public source are available under the MIT license. Official installers do not require a Heliox subscription.

Free software; local resource cost

Local language models

Ollama can run a model on your own computer without per-request API charges. You supply storage, memory, electricity, and suitable CPU/GPU capacity. Model weights are separate downloads.

Optional provider cost

APIs or existing subscriptions

OpenAI, Anthropic, Gemini, or another configured provider may charge for API usage. Heliox 0.13.0 can alternatively use an eligible Codex or Claude Code subscription through the official CLI. Heliox adds no fee, but provider-owned model access, quotas, and plan terms still apply.

Optional local downloads

Voice models

Kokoro and Pocket TTS run locally and do not need a speech API key. Their packages and weights consume disk, CPU time, download bandwidth, and temporary worker memory during speech. The worker exits after a short idle window; if synthesis is unavailable, Heliox can fall back to the operating-system voice.

No required specialist hardware

Camera, microphone, and neural work

Text workflows need no camera, microphone, or EEG device. Voice, gaze, and gesture need compatible hardware. Synthetic and recorded-EEG development needs no headset; live EEG research requires separately purchased compatible equipment.

Not for sale

Hosted Heliox service

No paid hosted Heliox plan or price has been announced. If one is introduced later, this page must state the price, included usage, data path, and relationship to the free MIT-licensed core.

Budget rule

How to keep Heliox at zero software cost

Use the MIT-licensed application, an existing computer, an installed Ollama model, operating-system speech, and no paid integrations. “Free” does not remove ordinary electricity, internet, storage, or hardware costs.
