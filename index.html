terminal
# Clone and install daemon
git clone https://github.com/VyomKulshrestha/Heliox-OS.git
cd Heliox-OS/daemon
pip install -e ".[all,dev]"
# Run the daemon
python -m pilot.server
# Run the frontend (separate terminal)
cd tauri-app/ui && npm ci && npm run dev

Requires Python 3.11+. The desktop app starts the local daemon automatically. Browser-only UI development requires a manually started daemon.
