Measured software evidence · 16 August 2026

Benchmarks with boundaries.

The public evidence bundle records distributions, regression controls, raw data, reproduction commands, and known exclusions. These are software-path measurements on one Windows host—not universal device, provider, network, or human-accuracy claims.

Guarded local path

27.229 ms

Median across 100 ready-daemon CPU-status requests; 29.476 ms p95 and zero model calls.

Intent controls

59 / 59

A fixed deterministic routing regression set, not population-level language accuracy.

Shared-loop health

65 ticks

Concurrent scheduler heartbeats during a real one-second CPU sample; 24.065 ms maximum gap.

Learned risk

36k / 5.4k

Training and temporal-validation samples for a bounded disk/process predictor; deterministic policy remains authoritative.

Codex CLI planning

3 / 3

Fixed planning-only cases at 14.708 s median; one account, no action execution, and zero destructive actions.

What these numbers exclude

Model-provider and network latency, browser page loads, UI rendering, microphone capture, audible TTS, camera, gesture, gaze, live EEG, and human accuracy all require separate evidence.

terminal
# Clone and install daemon
git clone https://github.com/VyomKulshrestha/Heliox-OS.git
cd Heliox-OS/daemon
pip install -e ".[all,dev]"
# Run the daemon
python -m pilot.server
# Run the frontend (separate terminal)
cd tauri-app/ui && npm ci && npm run dev

Requires Python 3.11+. The desktop app starts the local daemon automatically. Browser-only UI development requires a manually started daemon.
