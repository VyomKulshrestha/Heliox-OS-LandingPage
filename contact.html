Trust and contact

Reach the right Heliox OS channel.

Heliox OS is an MIT-licensed open-source desktop-agent project maintained by Vyom Kulshrestha. Choose the channel that matches your request, and never send credentials or private machine data through a public forum.

Product questions

Use GitHub Discussions for installation questions, product feedback, proposals, and public technical discussion. Use GitHub issues for reproducible defects and scoped feature requests.

Community

The Heliox Discord is available for informal conversation. Do not post API keys, OAuth files, private logs, personal files, screenshots, or vulnerability details in a public channel.

Private reporting

Security

Report vulnerabilities through the private GitHub security advisory form. Do not open a public issue for an unpatched vulnerability.

Privacy and maintainer email

Privacy questions may be sent to vyomkulshrestha2004@gmail.com. Never include model-provider credentials, local audit databases, raw screen captures, or other secrets unless a secure process has been agreed first.
